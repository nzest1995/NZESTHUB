# 🌐 NZEST ECOSYSTEM - Official Web & GitHub Pages

เว็บไซต์ Official Landing Page สำหรับ **NZEST Creator Studio Ecosystem** พร้อมเผยแพร่ขึ้น **GitHub Pages** ฟรี 100% ภายใน 2 นาที

---

## 📁 โครงสร้างไฟล์ในโฟลเดอร์นี้

* `index.html`: หน้าเว็บหลัก สไตล์ Dark Cyber Glassmorphism & Neon Glow (Responsive รองรับมือถือและคอมพิวเตอร์)
* `styles.css`: สไตล์การตกแต่ง แอนิเมชัน และแสงนีออนระดับพรีเมียม
* `app.js`: ระบบ Interactive, ป๊อปอัปสั่งซื้อ, หน้าต่างดาวน์โหลด และ Smooth Scroll
* `assets/`: โฟลเดอร์รูปภาพ, โลโก้, QR Code และไอคอน

---

## 🚀 วิธีการเปิดใช้งานบน GitHub Pages (ทำได้ 2 วิธี)

### 📌 วิธีที่ 1: สร้างเป็นเว็บไซต์หลักประจำตัว (แนะนำที่สุด - ได้ URL สั้น `https://nzest1995.github.io`)

1. ไปที่ **GitHub** ➔ กดปุ่ม **New Repository**
2. ตั้งชื่อ Repository ให้ตรงกับ Username ของคุณเป๊ะๆ คือ:
   👉 **`nzest1995.github.io`** (ตั้งเป็น Public)
3. ก๊อปปี้ไฟล์ทั้งหมดในโฟลเดอร์ `NZEST WEB` นี้ (`index.html`, `styles.css`, `app.js`, โฟลเดอร์ `assets/`) อัปโหลดขึ้น Repository นั้น
4. **เสร็จสิ้น!** เว็บไซต์จะออนไลน์ทันทีที่ลิงก์:
   🔗 **`https://nzest1995.github.io`**

---

### 📌 วิธีที่ 2: เผยแพร่ผ่าน Repository เดิม (`nzest1995/NZESTHUB`)

1. สร้างโฟลเดอร์ชื่อ `docs` ใน Repo `NZESTHUB` หรืออัปโหลดไฟล์เว็บไปไว้ที่โฟลเดอร์หลัก (Root)
2. ไปที่หน้า GitHub Repo `NZESTHUB` ➔ กดแท็บ **Settings**
3. เมนูด้านซ้ายเลือก **Pages**
4. ตรง **Branch** ให้เลือก `main` และเลือกโฟลเดอร์ `/ (root)` หรือ `/docs` ➔ กด **Save**
5. รอ 1-2 นาที เว็บไซต์จะเปิดใช้งานได้ที่:
   🔗 **`https://nzest1995.github.io/NZESTHUB/`**
